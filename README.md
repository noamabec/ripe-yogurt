# RIPE Yogurt · אתר חנות לגלידה ויוגורט

אתר תדמית וחנות למותג פיקטיבי של רשת גלידה ויוגורט קפוא, שנבנה לתיק עבודות.

## איך מריצים

האתר סטטי (HTML, CSS ו-JavaScript), אבל משתמש במודולי ES, ולכן צריך שרת מקומי ולא פתיחה ישירה של הקובץ:

```
npx serve .
```

או, במחשב בלי Node, עם הסקריפט שמצורף:

```
powershell -ExecutionPolicy Bypass -File serve.ps1 -Root . -Port 5180
```

ואז לפתוח את http://localhost:5180

## מה יש באתר

- דף בית עם הירו בעומק (פירות בשלוש שכבות), יוגורט בהרכבה מקוצר, מה בעונה והכי אהובים
- גלידות: 24 טעמים עם סינון, חיפוש ורכיבים ואלרגנים, מארזים, כוסות, עוגות וכרטיס מתנה
- עמוד מוצר עם בחירת גודל וטעמים
- יוגורט בהרכבה: גודל, בסיס, פירות העונה, קראנץ' ורוטב, והתוספות נוחתות על הכוס
- סל וקופה (משלוח או איסוף, קופון). התשלום לא מחובר: "לתשלום" מעביר את ההזמנה ל-WhatsApp
- סניפים, הסיפור שלנו, שאלות נפוצות, צור קשר, תקנון, פרטיות והצהרת נגישות
